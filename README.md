# 中文元音共振峰看看

一个单文件网页：录一段声音，量出 F1 / F2 / F3 和音高 F0，跟普通话十个单元音的参考值摆在一起看。

用来做嗓音训练里的**共振峰**练习。音高（F0）是声带的事，共振峰是声道形状的事，这两个得分开看。

在线版：<https://v01d-project.github.io/formant-look/>

## 用法

打开网页 → 选参考（女声 / 男声）→ 点「开始录」→ 念一个字把韵母拖长 2 秒 → 点「停」。

- 「存为 A」/「存为 B」：练习前后各存一次，页面会显示 F1 / F2 / F0 的差值。
- 「目标」下拉框：指定要练哪个韵母，页面按它算差值；留「自动」就按最近的那个算。
- 「选音频文件」：打不开麦克风时，把手机或别的软件录好的音频拖进来。
- 数据在浏览器本地算，不联网、不存盘。

## 参考值从哪来

## 它在算什么

- **共振峰**：对 40 ms 窗做 LPC（12 阶、16 kHz 采样）估频谱包络，在包络上按突出度找峰，峰顶用抛物线插值细化。
- **音高**：归一化自相关，取第一个足够强的峰并做倍频校正。
- **整段录音**：按 20 ms 步长切帧，逐帧算，取有声帧的中位数；最多分析 300 帧，20 秒录音约 0.25 秒算完。

## 读数怎么信

本页读数比上面那张表普遍高 50–110 Hz，因为预加重和 LPC 包络的固有偏差。

所以适合看**同一个人前后两次的变化**，不适合拿来跟文献数值硬对。合成元音上的验证：女声 /a/（真值 850 / 1450 / 190）测出 900 / 1463 / 190，女声 /i/（350 / 2700）测出 457 / 2730。

复韵母（ai、ao、ian 之类）是滑动的，量单帧没意义，这页只管十个单元音。

## 别人怎么用

单文件、无依赖、无后端。双击 `index.html` 能开，放任意静态托管也行。
