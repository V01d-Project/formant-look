# 共振峰看看

一个单文件网页，录一段声音，量出 F1 / F2 / F3 和音高 F0，把测量点画在 F1–F2 平面上。

用来做嗓音训练里的**共振峰**练习：音高（F0）是声带的事，共振峰是声道形状的事，两者的数值要分开看。

## 用法

打开网页 → 点「开始录」→ 说一句话或者把一个元音拖长 2 秒 → 点「停」。

- 「存为 A」/「存为 B」：练习前后各存一次，页面会显示 F1 / F2 / F0 的差值。
- 「选音频文件」：打不开麦克风时，把手机或别的软件录好的音频拖进来。
- 数据在浏览器本地算，不联网、不存盘。

## 它在算什么

- **共振峰**：对 40 ms 窗做 LPC（12 阶、16 kHz 采样）估频谱包络，在包络上按突出度找峰，峰顶用抛物线插值细化。
- **音高**：归一化自相关，取第一个足够强的峰并做倍频校正。
- **整段录音**：按 20 ms 步长切帧，逐帧算，取有声帧的中位数；最多分析 300 帧，20 秒录音约 0.3 秒算完。

## 读数怎么信

页面读数普遍比教科书的经典数值（Peterson & Barney 女声组：啊 850/1220、衣 310/2790、乌 370/950）高 50–100 Hz，因为预加重和 LPC 包络的固有偏差。

所以这个页面适合看**同一个人前后两次的变化**，不适合拿来跟文献数值硬对。

## 别人怎么用

单文件、无依赖、无后端。直接双击 `index.html` 打开也行，放到任意静态托管上也行。
